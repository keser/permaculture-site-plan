# Permaculture Master Site Plan

Long-term master site plan for a **0.43-acre residential property in the
Portland, CT area** (~41.6°N). Independent of any course — the two long-term
stakeholders (the owner and his father) hold full authority over scope,
timeline, and content.

Public *during* development, not just after, to show the technical design
approach as it's built.

> **Privacy:** these docs never state the exact street address or parcel
> number. The property is referred to generically. Exact parcel records
> (survey PDFs, lot spreadsheets) are kept in a private folder, never here.

## Layout

```
site-plan/
├── site-profile.md            — climate, solar, sector & passive-design reference
├── project-plan-overview.md   — denormalized rollup of every task across all phases
├── phase-1-reset.md           — clearing, mulching, garden reorganization
├── phase-2-construction.md    — spigots, water line, panel upgrade, new shed
├── phase-3-establish-systems.md — compost, forage/cover crops, water harvesting, pond
├── phase-4-diversity-habitat.md — native trees/shrubs, pollinator plantings, perennials
├── design-phase.md            — ongoing design work, runs alongside the active phase
├── progress-log.md            — dated narrative: on-site work + why the plan changed
├── maps/                      — exported Figma base maps
└── sketches/                  — dated iPad Pro scans
inspiration/                   — public inbox: links, images, references
```

## Phases

Numbered phases run roughly in sequence — a phase's dependent tasks wait on the
ones before it — with two deliberate exceptions: **Design** runs alongside
whatever phase is active, and as of 2026-09-03 **Construction** is decoupled from
Reset and runs independently.

| Phase | Scope | Status (Sep 2026) |
|---|---|---|
| 1 — Reset | Clear invasives & deadwood, limb trees, mulch, shrink the garden footprint | In progress |
| 2 — Construction | Water spigots + line to the back, electrical panel upgrade, new 10×8 shed | Not started |
| 3 — Establish Systems | Hot/cold compost, forage & cover crops, mushroom logs, roof water harvesting, pond | Hot compost started early; rest not started |
| 4 — Diversity & Habitat | Native trees & shrubs, pollinator flowers, perennial back-fence bed, hops/grapes/blueberries | Not started |
| Design (ongoing) | Shed + whole-property storage layout; the full 5-year vision | In progress |

Tasks are ID-prefixed by phase (`R` Reset, `C` Construction, `S` Establish
Systems, `D` Diversity, `DS` Design) and may depend across phases. Each phase
file carries current task status; `progress-log.md` carries the history and the
rationale behind scope revisions, newest first.
