# Phase 1 — Reset

Clear the site of invasive species, deadwood, and clutter. The first eight tasks below have no
dependencies on each other and should be done first, in the order listed. Everything else in this
phase depends on that clearing being done — including the wood pile move and, later, the raised
beds and wood chips, which additionally wait on the Construction phase (see
[Phase 2 — Construction](phase-2-construction.md)).
