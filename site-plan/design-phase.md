# Design (Ongoing)

Not a sequential phase — this one spans the entire 5-year vision for the property and runs
alongside whichever numbered phase is currently active. The only rule: don't design something that
belongs to the phase currently under construction (design has to land before the build it feeds
starts, e.g. DS1 before C5). New design tasks get added here as new construction needs are
identified.

| ID | Task | Description | Depends On | Status | Source |
