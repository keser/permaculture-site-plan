# Project Plan Overview

Consolidated view of every task across all phases. Each phase also has its own file with the same
tasks in more detail — this file exists to see the whole project, its dependencies, and status at a
glance without opening every file.

Phase files: [Phase 1 — Reset](phase-1-reset.md) · [Phase 2 — Construction](phase-2-construction.md) · [Phase 3 — Establish Systems](phase-3-establish-systems.md) · [Phase 4 — Diversity & Habitat](phase-4-diversity-habitat.md) · [Design (Ongoing)](design-phase.md)

Phases 1–4 are sequential in the sense that each phase's dependent tasks wait on the ones before
it. **Design is the exception** — it runs alongside whatever numbered phase is active, gated only by
"don't design what's currently being built."

## Notes

- Status values: Completed / In Progress / Further Research Required / Yet to Begin / **On Hold — Conditional** (added for tasks deliberately shelved pending a future decision, e.g. R9).
- All tasks currently sourced from the Lesson 2 client interview (2026-07-19), except this revision's restructuring (2026-07-21). Update `Source` per task as later lessons (water, soils, trees, etc.) add or refine tasks.
- Cross-phase dependencies (e.g. D3 depends on R17, a Phase 1 task) are intentional — a task doesn't have to depend only on tasks within its own phase.
- **R7 (Remove chain-link hedge)** was removed — redundant with R1.
- **S9 (Barn)** was removed — Dad's mention was part of an "anything possible" hypothetical that also included moving the house, which is off the table.
- Former R11–R15 were renumbered to C1–C5 under the new Construction phase.
