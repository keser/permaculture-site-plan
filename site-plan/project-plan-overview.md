# Project Plan Overview

Consolidated view of every task across all phases. Each phase also has its own file with the same
tasks in more detail — this file exists to see the whole project, its dependencies, and status at a
glance without opening every file.

Phase files: [Phase 1 — Reset](phase-1-reset.md) · [Phase 2 — Construction](phase-2-construction.md) · [Phase 3 — Establish Systems](phase-3-establish-systems.md) · [Phase 4 — Diversity & Habitat](phase-4-diversity-habitat.md) · [Design (Ongoing)](design-phase.md)

Phases 1, 3, and 4 are sequential in the sense that each phase's dependent tasks wait on the ones
before it. **Two exceptions:** Design runs alongside whatever numbered phase is active, gated only
by "don't design what's currently being built"; and as of 2026-09-03, Phase 2 (Construction) is no
longer gated on Phase 1 and runs independently (see [progress-log.md](progress-log.md)).
